# 📊 E-Commerce Sales Analysis - Power BI

## 🔎 Project Overview
This project analyzes e-commerce sales data to identify sales trends, profitability, and top-performing products. The dashboard was built using Power BI with proper data modeling and DAX measures.

---

## 🛠 Tools & Technologies
- Power BI
- DAX (Data Analysis Expressions)
- Power Query (Data Cleaning)
- Star Schema Data Modeling
- GitHub (Project Documentation)

---

## 🧹 Data Cleaning Steps
- Removed null values
- Trimmed unnecessary spaces
- Corrected data types (Date, Numeric)
- Created Dim Date table
- Established relationships between fact and dimension tables

---

## 📐 Data Modeling
- Implemented Star Schema
- Fact Table: Sales Data
- Dimension Tables: Date, Product, Region
- Created one-to-many relationships

---

## 📈 Key DAX Measures
- Total Sales
- Total Profit
- Total Quantity
- Profit Margin
- Top N Products

---

## 💡 Business Insights
- Identified highest revenue-generating products
- Analyzed regional performance
- Detected products with high sales but low profitability
- Observed monthly sales trends
